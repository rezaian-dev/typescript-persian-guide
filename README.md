## 🧹 ساختار این مخزن

این مخزن **فقط برای انتشار نهایی کتاب** است: PDF، صفحات آنلاین، تصویرها، فونت‌ها و فایل‌های مرورگری ضروری. سورس توسعه، ابزار ساخت، تست‌ها، تنظیمات CI و فایل‌های نصب وابستگی در شاخهٔ فعلی نگه‌داری نمی‌شوند.

فایل‌های مرورگری و تصویر صفحات، بخشی از خود خوانشگر هستند؛ حذف آن‌ها نمایش کتاب یا تعامل‌های سایت را خراب می‌کند. انتشار مستقیم از پوشهٔ `docs/` انجام می‌شود.
