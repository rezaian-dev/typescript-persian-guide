Why this book

مدل ذهنی، نه حفظ قاعده

هر مفهوم اول روی مدل کامپایلر می‌نشیند؛ بعد در کد راستی‌آزمایی‌شده و پروژه واقعی پیاده می‌شود.

زیر کاپوت کامپایلر

هر ۴۰ فصل بخش «زیر کاپوت — چرا این‌طور است؟» دارد: freshness و widening، گراف جریان کنترل، variance و منطق مجموعه‌ای نوع‌ها.

کد راستی‌آزمایی‌شده

هر ۱۸۶ قطعه‌کد با tsc رسمی بررسی شده — روی TypeScript 7.0.2 و 6.0.3 با صفر خطا؛ خطاهای عمدی هم با پیام واقعی کامپایلر آمده‌اند.

همگام با TypeScript 7

کامپایلر native جدید، گذار ۶ به ۷، NoInfer، const type parameters و satisfies — با مرزبندی روشن زبان و پیاده‌سازی.

طراحی نوع پیشرفته

conditional و mapped types، template literals، type-level programming با مرز مهندسی مشخص: کِی بسازیم و کِی نه.

Production واقعی

اعتبارسنجی مرزی با Zod، الگوی Result، ماشین حالت تایپ‌شده، React و Next.js، انتشار پکیج — با ۸ پروژه کامل.

آمادگی مصاحبه

+۱۳۰ پرسش با پاسخ تشریحی: دو پرسش تخصصی در پایان هر فصل و ۵۰ پرسش سطح‌بندی‌شده از Junior تا Senior در پیوست.
